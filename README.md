# User Roster Management Application

This Flask application allows you to upload an Excel file containing user data, store it in MongoDB, and manage the records through a web interface.

## Features

- Upload Excel files (.xlsx, .xls) with user roster data
- Automatic import to MongoDB
- View all users in a table format
- Edit user information
- Delete users
- Responsive UI using Bootstrap

## Requirements

- Python 3.6+
- MongoDB installed and running
- Flask and other dependencies (see below)

## Installation

1. Clone this repository or download the source code

2. Create a virtual environment (recommended):
   ```
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   ```

3. Install required packages:
   ```
   pip install -r requirements.txt
   ```

4. Make sure MongoDB is running on your system
   - Default connection: mongodb://localhost:27017/

## Running the Application

1. Make sure MongoDB is running on your system

2. Start the Flask application:
   ```
   python app.py
   ```

3. Open your web browser and navigate to:
   ```
   http://localhost:5000
   ```

## Excel File Format

Your Excel file should contain user data with column headers. The application will use these headers as field names in MongoDB.

Example Excel format:
| First Name | Last Name | Email               | Department | Position    |
|------------|-----------|---------------------|------------|-------------|
| John       | Doe       | john.doe@email.com  | IT         | Developer   |
| Jane       | Smith     | jane.smith@email.com| HR         | Manager     |
| ...        | ...       | ...                 | ...        | ...         |

## MongoDB Structure

The application creates a database named `userRoster` with a collection named `users`.

Each user document will contain fields corresponding to the columns in your Excel file, plus a unique `_id` field generated by MongoDB.

## Customization

- To change the MongoDB connection settings, edit the `MONGO_URI` in `app.py`
- To allow additional file types, modify the `ALLOWED_EXTENSIONS` in `app.py`
- To customize the appearance, edit the templates or add custom CSS
